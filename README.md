## Краткое описание программы
Программа принимает на вход размер одномерного массива целых чисел (от 1 до 100), выполняет валидацию ввода и считывает сами элементы. Затем рассчитываются базовые метрики (минимум, максимум, сумма, среднее арифметическое, знаки элементов, чётность), выполняется фильтрация по интервалу `[a, b]`, а также вычисляется длина самого длинного непрерывного строго возрастающего фрагмента массива (индивидуальный вариант №6).

## Команда компиляции и запуска
```bash
gcc main.c -Wall -Wextra -Wpedantic -std=c11 -o homework1
./homework1
```

## Описание входных данных
* Размер массива `size` — целое число от 1 до 100.
* Элементы массива — последовательность из `size` целых чисел, вводимых через пробел или с новой строки.
* Границы фильтрации `a` и `b` — два целых числа.

## Перечень реализованных функций
* `inputArray` — ввод элементов массива с проверкой типов данных.
* `printArray` — вывод массива в одну строку.
* `findMin` — поиск индекса первого минимального элемента.
* `findMax` — поиск индекса первого максимального элемента.
* `calculateSum` — вычисление суммы элементов (`long long` во избежание переполнения).
* `calculateAverage` — вычисление вещественного среднего значения.
* `performIndividualTask` — алгоритм поиска максимального монотонно возрастающего подмассива.
